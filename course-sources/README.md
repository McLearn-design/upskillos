# Course YAML sources

Keep editable YAML source files for generated courses in this folder. Start by copying [`docs/templates/course-template.yaml`](../docs/templates/course-template.yaml), then follow [`docs/contributing/course-from-yaml.md`](../docs/contributing/course-from-yaml.md).

Commit the YAML source together with its generated files under `src/courses/`. Future contributors and coding agents should edit the YAML and regenerate the course so both representations stay synchronized.
