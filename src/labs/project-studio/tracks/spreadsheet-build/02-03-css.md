HTML says *what* is on the page. How it looks (colours, lines, sizes, spacing) is written in a second language, **CSS** (Cascading Style Sheets). Keeping them apart means you can restyle the whole sheet without touching its structure.

## Link a stylesheet

Add one line to the `<head>` of `index.html`, under the title:

```html file=index.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Spreadsheet</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Spreadsheet</h1>
    <table>
      <thead>
        <tr>
          <th></th>
          <th>A</th>
          <th>B</th>
          <th>C</th>
          <th>D</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <th>1</th>
          <td>Item</td>
          <td>Price</td>
          <td>Qty</td>
          <td>Total</td>
        </tr>
        <tr>
          <th>2</th>
          <td>Coffee</td>
          <td>3.50</td>
          <td>2</td>
          <td></td>
        </tr>
        <tr>
          <th>3</th>
          <td>Bagel</td>
          <td>2.25</td>
          <td>3</td>
          <td></td>
        </tr>
        <tr>
          <th>4</th>
          <td></td>
          <td></td>
          <td></td>
          <td></td>
        </tr>
      </tbody>
    </table>
  </body>
</html>
```

`<link>` connects another file to the page. `rel="stylesheet"` says what kind of connection it is, and `href="style.css"` names the file. `href` is a **relative path** (lesson 0.1): relative to the folder `index.html` is in.

```check
contains index.html "<link rel=\"stylesheet\" href=\"style.css\">" -- Add the <link> line inside <head>.
```

## The stylesheet

This step opens `style.css`. Type:

```css file=style.css
body {
  font-family: system-ui, sans-serif;
  margin: 24px;
}

table {
  border-collapse: collapse;
}

th,
td {
  border: 1px solid #d0d7de;
  padding: 4px 8px;
  min-width: 80px;
  height: 24px;
  font-size: 13px;
}

th {
  background: #f3f4f6;
  color: #57606a;
  font-weight: 600;
}

thead th {
  position: sticky;
  top: 0;
}
```

Refresh the browser. It's a spreadsheet now: grey grid lines, shaded headers, cells of an even size.

### How CSS is written

CSS is a list of **rules**. Each rule is a **selector**, saying which elements it applies to, then `{ }` around **declarations**, each a property, `:`, a value and `;`:

```css
td {
  border: 1px solid #d0d7de;
}
```

reads: for every `td` element, draw a border 1 pixel wide, solid, in the colour `#d0d7de`.

- **`body { ... }`** applies to the `<body>` element. `font-family` picks the font: `system-ui` is your operating system's own interface font, and `sans-serif` is the fallback if that isn't available. `margin: 24px` puts space around the page's edge.
- **`table { border-collapse: collapse; }`** makes neighbouring cells share one border line instead of each drawing its own. Without it, every cell has a double outline.
- **`th, td { ... }`**: a comma between selectors means "both". Every cell, header or data, gets the border, **padding** (space between the border and the text), a minimum width and a height.
- **Colours** like `#d0d7de` are written in hexadecimal: two digits each for red, green and blue, from `00` (none) to `ff` (full). `#d0d7de` is a light blue-grey.
- **`th { ... }`** shades the header cells. This rule comes after `th, td`, and both apply to headers. When two rules set the *same* property, the later one wins; these set different properties, so headers get both.
- **`thead th { ... }`**: a space between selectors means "inside". This selects `th` elements *inside* a `thead`: the column letters, not the row numbers. `position: sticky; top: 0;` keeps them at the top of the window when the page scrolls. With 4 rows nothing scrolls yet; with 100 rows in sprint 3, you'll see the letters stay put.

### The box model

Every element is drawn as a box, from the inside out: the **content** (the text), the **padding** around it, the **border** around that, and the **margin** outside the border, which separates it from its neighbours. Almost every layout question in CSS ("why is there a gap here?") comes down to one of those four.

```check
file style.css
page index.html "getComputedStyle(document.querySelector('table')).borderCollapse" collapse label="the table's borders collapse into single lines"
page index.html "getComputedStyle(document.querySelector('td')).borderTopStyle" solid label="data cells have a solid border"
page index.html "getComputedStyle(document.querySelector('thead th')).position" sticky label="the column headers are sticky"
page index.html "getComputedStyle(document.querySelector('tbody th')).position" static label="the row numbers are not sticky"
```

## Commit

```powershell
git add style.css
git commit -am "Style the grid like a spreadsheet"
```

`git add style.css` first, because `-a` only stages files Git already tracks, and `style.css` is new.

```check
git-tracked style.css -- git add style.css, then commit.
git-clean
```
