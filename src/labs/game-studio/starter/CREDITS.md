# Game Studio starter art: credits

Every image in this folder is by **Kenney** (www.kenney.nl) and is public domain under
**Creative Commons Zero (CC0)**. Kenney's support page (checked 2026-09-30) says:
> "all game assets on the asset pages are public domain licensed (CC0). You're free to use them, even in
> commercial projects."

Credit is not required, but is given here anyway. The Kenney logo is not used anywhere: it is reserved for
Kenney's own projects. Each pack's own licence file is kept beside it, as the pack shipped it.

| Folder | Pack | From | What is included |
|---|---|---|---|
| `pixel-platformer/` | Pixel Platformer 1.2 | kenney.nl/assets/pixel-platformer | All 18 × 18 tiles, characters and backgrounds; the packed tilemaps |
| `tiny-dungeon/` | Tiny Dungeon | kenney.nl/assets/tiny-dungeon | All 16 × 16 tiles and the packed tilemap |
| `top-down-shooter/` | Top-down Shooter | kenney.nl/assets/top-down-shooter | Four characters (soldier, zombie, robot, survivor), weapons, the tile sheets |
| `puzzle-pack/` | Puzzle Pack 2 | kenney.nl/assets/puzzle-pack-2 | Paddles, balls, white particles, and tiles (bricks) in blue, green, red and yellow |
| `ui-pack/` | UI Pack | kenney.nl/assets/ui-pack | The blue and grey default-size buttons, panels and icons |

**Changes made:** file names are lowercased, with spaces as dashes, so they are valid project paths
(`assets/…`). The images themselves are unchanged. Only a subset of each pack is included, to keep the app
small; the full packs are free at the addresses above.

**Not included yet:** Kenney's interface and impact sound packs (also CC0). They come in with the audio node,
because until then nothing in a project can play them.
